# Patricia Sáez · Digital Creator

## Run Locally

**Prerequisites:** Node.js 20.19+ or 22.12+.

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Open the local URL printed by Vite (by default, `http://localhost:3000`).

No API key or `.env.local` file is needed to run the portfolio.

Run `npm run lint` to check TypeScript and `npm run build` to create a production build.
